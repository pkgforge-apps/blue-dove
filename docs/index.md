tagline: A fast music player with an album browser and waveform seekbar
lead: Point it at a directory and it plays. Native Rust, no database to build, no account, no network.
features:
  - title: Point it at a directory
    body: Blue Dove reads the tags already in your files and groups them into albums. Nothing is imported or copied, so the directory stays the truth.
  - title: See the track
    body: The waveform of the playing track is drawn from its samples. Click or drag anywhere in it to jump there.
  - title: Native and light
    body: One small binary drawn with egui. No browser engine, no runtime to install, and it stays quiet when nothing is playing.
  - title: Plays what you have
    body: FLAC, MP3, M4A, Ogg Vorbis, Opus and WAV, plus the formats game rips use. Every decoder is pure Rust.
  - title: Portable on Linux
    body: The onelf build and the AppImage each carry their own libraries, so they run on any distribution, musl ones included.
